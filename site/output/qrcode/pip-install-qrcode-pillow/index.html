Home › qrcode › pip install qrcode pillow

pip install qrcode pillow

Correct install

pip install "qrcode[pil]"

The [pil] extra declares Pillow as a dependency — one command installs both.

Error without Pillow

qrcode.exceptions.ModuleNotFoundError: No module named 'PIL'

Pillow is required for PNG and image-format output. Plain pip install qrcode omits it.

Verify

python -c "import qrcode; import PIL; print('ok')"
