qrcode installed but import still fails

Symptom

pip install qrcode  # Success
python -c "import qrcode"  # ModuleNotFoundError

Diagnose

Check which Python and pip are active:

which python
which pip
pip show qrcode

pip and python pointing to different paths means the install landed in the wrong environment.

Fix

python -m pip install "qrcode[pil]"

This installs into the exact interpreter python resolves to.

If using a virtual environment

source venv/bin/activate
python -m pip install "qrcode[pil]"
