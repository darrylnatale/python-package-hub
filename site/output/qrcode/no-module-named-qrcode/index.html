ModuleNotFoundError: No module named 'qrcode'

Error

ModuleNotFoundError: No module named 'qrcode'

Fix

pip install "qrcode[pil]"

Verify

python -c "import qrcode; print(qrcode.__version__)"

Why

The [pil] extra installs Pillow, which qrcode requires for image generation.
